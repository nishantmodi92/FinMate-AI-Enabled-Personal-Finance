# FinMate-AI-Enabled-Personal-Finance

A personal finance application concept exploring expense management, structured financial data, and AI-assisted user experiences.

Key engineering areas

Android UI development with Kotlin and Jetpack Compose

Local data persistence using Room

REST API integration with Retrofit

Firebase integration where applicable

Gemini or LLM API integration proof of concept

AI-assisted features designed around clear user workflows

Technology stack: Kotlin, Jetpack Compose, Room, Retrofit, Firebase, Gemini API / LLM API integration proof of concept.

Focus: Practical AI integration, maintainable mobile architecture, and useful personal finance experiences.
